Convertisseur de cartes GeoTIFF → PWA

Glisse tes GeoTIFF de parcours ici, remplis les infos, puis télécharge le pack complet (images + catalog.json) à déposer directement dans le dépôt GitHub de l'appli. Tout se passe dans ton navigateur — aucun fichier n'est envoyé sur un serveur.

1. Catalogue existant (optionnel)

Charge le catalog.json déjà en ligne pour ajouter tes nouvelles cartes à la suite, sans écraser ce qui existe.

2. Métadonnées lues sur les cartes (optionnel)

Si Claude t'a généré un fichier de métadonnées (nom, distance, niveau) à partir de captures de tes cartes, charge-le ici. Quand tu déposeras un .tif dont le nom correspond, les champs se rempliront automatiquement.

3. Ajouter des cartes

Formats acceptés: GeoTIFF (.tif / .tiff). Tu peux en glisser plusieurs à la fois.

Glisse tes fichiers .tif ici
ou clique pour parcourir tes fichiers

4. Parcours à inclure

Aucune carte ajoutée pour l'instant.

Ajoute un ou des fichiers GeoTIFF ci-dessus pour commencer.

5. Générer le pack

Ça va créer un fichier .zip avec toutes les images converties + le catalog.json à jour.

Une fois le .zip téléchargé : dézippe-le, puis glisse tout son contenu dans
ton dépôt GitHub (à la racine), par-dessus les fichiers existants.
